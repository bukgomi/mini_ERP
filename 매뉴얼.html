1이 프로그램은 무엇인가요?

엑셀로 하던 거래처·재고·미수금 관리를 훨씬 편하게 해주는 프로그램입니다.

이런 일을 해줍니다예시
매출·매입 기록품목 고르면 단가 자동 입력, 부가세 자동 계산
받을 돈(미수금) 관리"한빛상사에서 아직 70만 원 못 받았음"을 자동 계산
재고 관리입고·출고에 따라 재고 자동 증감, 부족하면 경고
거래명세서·견적서A4로 바로 인쇄 (거래명세서는 공급자/공급받는자 2부)
장부 (자체기장)매출장·매입장·현금출납부, 월계·누계 자동
세무사 자료 정리영수증·매출·매입·경비를 폴더 하나로 묶어서 전달
⚠️ 이것은 하지 않습니다 세금 신고, 전자세금계산서 국세청 전송, 4대보험 계산은 지원하지 않습니다. 매년 바뀌는 세법을 프로그램이 쫓아가면 오히려 위험하기 때문입니다. 신고는 세무사님 또는 홈택스에서 하시고, 이 프로그램은 자료 정리까지 책임집니다.

2준비물: 구글드라이브 설치하기 (10분)

이 프로그램에는 서버가 없습니다. 데이터는 내 컴퓨터의 폴더에 저장되고, 구글드라이브가 그 폴더를 자동으로 클라우드에 백업해 줍니다. 그래서 먼저 구글드라이브를 설치합니다.

💡 왜 구글드라이브인가요? ① 컴퓨터가 고장 나도 데이터가 클라우드에 살아있고 ② 다른 컴퓨터에서도 이어서 쓸 수 있고 ③ 무료(15GB)이기 때문입니다. 이미 쓰고 계시다면 이 장은 건너뛰세요.
1
인터넷 주소창에 google.com/drive/download 를 입력해 접속한 뒤 "데스크톱용 Drive 다운로드" 버튼을 누릅니다.
2
내려받은 GoogleDriveSetup.exe 를 더블클릭해 설치합니다. 설치가 끝나면 구글 계정으로 로그인하라는 창이 뜹니다. (지메일 주소와 비밀번호)
3
설치가 끝나면 파일 탐색기(📁 노란 폴더 아이콘)를 열어 보세요. 왼쪽 목록에 "Google Drive" 가 새로 생겨 있습니다. 그 안의 "내 드라이브"가 클라우드와 자동으로 연결되는 공간입니다.
4
내 드라이브 안에서 마우스 오른쪽 버튼 → 새로 만들기 → 폴더 → 이름을 미니ERP데이터 로 짓습니다. 이 폴더가 우리 회사 장부가 저장될 곳입니다.
5
(권장) 방금 만든 폴더에서 마우스 오른쪽 버튼 → 오프라인 액세스 → 오프라인으로 사용 가능을 선택해 두면, 인터넷이 끊겨도 프로그램을 계속 쓸 수 있습니다.
📁 내 드라이브
└─ 📁 미니ERP데이터 ← 여기에 모든 데이터가 저장됩니다
✅ 잘 되는지 확인하는 방법 폴더에 아무 파일이나 넣어 보세요. 파일 아이콘에 초록 체크(✓) 표시가 붙으면 클라우드 백업이 완료됐다는 뜻입니다. 구름(☁) 표시는 "클라우드에만 있음"이라는 뜻입니다.

3프로그램 실행하기 — 두 가지 방법

둘 중 편한 것 하나만 쓰면 됩니다. 데이터는 서로 완전히 호환됩니다.

방법 ① 파일 하나로 바로 쓰기 (미니ERP.html)

1
받은 파일 중 미니ERP.html 을 더블클릭합니다. Chrome(크롬) 또는 Edge(엣지) 브라우저에서 열립니다. 이게 전부입니다 — 설치가 없습니다.
2
(추천) 프로그램처럼 만들기: 크롬 오른쪽 위 점 세 개(⋮) 메뉴 → 저장 및 공유 → 바로가기 만들기 → "창으로 열기" 체크 → 만들기.
바탕화면에 아이콘이 생기고, 다음부터는 주소창 없는 독립 창으로 실행됩니다.
⚠️ 브라우저는 크롬 또는 엣지를 쓰세요 자동 저장에 필요한 "폴더 연결" 기능이 크롬·엣지에만 있습니다. 다른 브라우저에서는 수동 저장 모드로만 동작합니다.

방법 ② 설치형 프로그램 (미니ERP-Setup.exe)

1
미니ERP-Setup-1.0.0.exe 를 더블클릭해 설치합니다. "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 누르세요. (무료 프로그램이라 유료 인증서 서명이 없어서 뜨는 안내일 뿐, 이상이 있는 것이 아닙니다.)
2
설치 후 바탕화면의 미니 ERP 아이콘으로 실행합니다. 브라우저가 필요 없습니다.

4가장 중요한 한 가지: 데이터 폴더 연결 ⭐

이것만 하면 저장은 평생 자동입니다. 처음 한 번만 하면 됩니다.

1
프로그램을 열면 위쪽에 노란 안내 띠가 보입니다. 오른쪽의 파란 버튼을 누르세요.
📁 데이터 폴더가 연결되지 않았습니다. 구글드라이브 안의 폴더를 선택하면 자동 저장·백업됩니다.   데이터 폴더 연결
2
폴더 선택 창이 뜨면 내 드라이브 → 미니ERP데이터 (2장에서 만든 폴더)를 선택합니다.
3
"사이트에서 파일을 보고 수정하도록 허용하시겠습니까?" 라고 물으면 허용(수정)을 누릅니다.
4
화면 오른쪽 위에 저장됨 14:30:05 처럼 초록 표시가 보이면 성공입니다. 이제 무엇을 입력하든 자동으로 저장됩니다. 저장 버튼이 따로 없습니다.
💡 앞으로 어떻게 저장되나요? 입력할 때마다 자동 저장 → 하루 한 번 자동 백업(30일치 보관) → 구글드라이브가 클라우드로 백업. 창을 닫는 순간에도 마지막 입력까지 저장하고 닫힙니다. 3중 안전장치입니다.
⚠️ 가끔 "폴더 다시 연결" 이라고 떠요 브라우저 보안 규칙 때문에 가끔 권한을 다시 물어봅니다. [폴더 다시 연결] 버튼 → 허용 만 누르면 됩니다. 데이터는 그대로 있습니다.

5처음 설정 (5분)

5-1. 회사 정보 입력

1
왼쪽 메뉴 맨 아래 시스템 → 데이터·설정으로 갑니다.
2
상호, 대표자, 사업자번호, 주소, 전화, 계좌번호를 입력하고 [회사 정보 저장]을 누릅니다. 이 내용이 견적서·거래명세서의 공급자 칸에 자동으로 인쇄됩니다.

5-2. 우리 회사에 맞는 기능만 켜기

같은 화면의 모듈 켜기/끄기에서 업종에 맞게 스위치를 조절하세요.

업종추천 설정
물건을 파는 회사 (도소매)기본 그대로 + 배송·출고 켜기
서비스업 (재고 없음)품목·재고 끄기 → 매출 입력 시 품명을 직접 적게 됩니다
영수증 정리가 필요한 회사경비 관리 + 증빙·세무사 켜기
💡 걱정 마세요 기능을 꺼도 데이터는 절대 지워지지 않습니다. 다시 켜면 그대로 보입니다.

5-3. 미리 둘러보고 싶다면

설정 화면의 [예시 데이터 넣기]를 누르면 가상의 거래처·매출·재고가 채워져서 화면들을 미리 구경할 수 있습니다. 실제 사용 전에 [전체 데이터 초기화]로 지우면 됩니다.

6매일 쓰는 기능

실제 업무 순서 그대로: 거래처 등록 → 매출 입력 → 명세서 인쇄 → 수금 기록

6-1. 거래처 등록 (처음 한 번)

1
기초 정보 → 거래처 관리 → [+ 거래처 등록]. 상호만 입력해도 됩니다.
2
프로그램 쓰기 전부터 못 받은 돈이 있는 거래처라면 기초 이월 잔액 칸에 그 금액을 넣으세요. (예: 500,000) 미수금 계산에 자동으로 합산됩니다.

6-2. 품목 등록 (판매업만)

구매·재고 → 품목·재고 → [+ 품목 등록]. 품명·판매가·매입가와 지금 창고에 있는 수량(기초재고)을 입력하세요. 안전재고를 넣으면 재고가 그 아래로 떨어질 때 대시보드에 경고가 뜹니다.

6-3. 매출 입력 (물건을 팔았을 때)

1
영업 관리 → 매출 관리 → [+ 매출 등록]
2
거래처를 고르고, 품목을 고르면 단가가 자동으로 들어갑니다. 수량만 입력하세요.
3
부가세는 자동 계산됩니다(공급가액의 10%). 부가세 없는 거래면 "부가세 미적용" 체크.
4
[저장]. 매입도 같은 방법입니다 — 단, 매입은 상태를 "입고완료"로 바꿔야 재고가 늘어납니다.

6-4. 거래명세서 인쇄

1
매출 목록에서 그 건의 [명세서] 버튼을 누릅니다.
2
내용을 확인하고 [발행 후 인쇄] → 미리보기가 뜨면 [🖨 인쇄].
3
A4 가로 한 장에 공급자 보관용 + 공급받는자 보관용 2부가 나란히 인쇄됩니다. 전잔금(이전에 못 받은 돈)·오늘 입금·남은 잔액도 자동으로 계산되어 들어갑니다.
💡 종이 대신 파일로 보내려면 인쇄 창에서 프린터 대신 "PDF로 저장"을 선택하세요. 저장된 PDF를 카톡·문자·이메일로 보내면 됩니다.

6-5. 돈을 받았을 때 (수금)

1
매출 목록에서 [수금] 버튼 → 받은 금액 입력 → [수금 기록].
2
일부만 받아도 됩니다. 100만 원 중 30만 원만 받으면 자동으로 부분수금 표시가 되고 미수금 70만 원이 남습니다.
3
거래처별로 받을 돈이 얼마나 남았는지는 영업 관리 → 수금·지급 메뉴에서 한눈에 봅니다. 오래 밀린 순서(30일/60일/90일)도 자동 분류됩니다.

7엑셀로 한 번에 넣기

기존에 엑셀로 관리하던 거래처·품목·장부를 하나씩 입력할 필요 없습니다.

1
거래처 관리(또는 품목·재고, 매출 관리) 화면 위의 [📄 엑셀 양식 받기]를 눌러 양식 파일을 받습니다.
2
엑셀에서 양식을 열고, 예시 줄을 지운 뒤 데이터를 붙여넣어 저장합니다. 열 순서가 달라도, 일부 열이 비어도 괜찮습니다.
3
[📥 엑셀 업로드] → 파일 선택 → 미리보기 화면에서 몇 건이 새로 들어오는지, 중복은 없는지 확인하고 [가져오기].
어디서무엇을 올리나참고
거래처 관리거래처 목록같은 상호·사업자번호는 중복으로 걸러줌
품목·재고품목 목록현재 수량을 "기초재고" 열에 넣으세요
매출/매입 관리과거 거래 이력한 줄 = 거래 1건. 없는 거래처는 자동 등록 가능
⚠️ 과거 매출 이력을 올릴 때 주의 품명이 등록된 품목과 똑같으면 재고가 자동으로 차감됩니다. 이미 현재 재고를 기초재고에 입력해 두었다면 이중으로 계산될 수 있어요 — 업로드 화면의 노란 경고를 확인하고, 필요하면 업로드 후 [재고조정]으로 수량을 맞추세요.

반대로 [📤 엑셀 다운로드]를 누르면 현재 목록이 진짜 엑셀 파일(.xlsx)로 저장됩니다.

8데이터는 안전한가요? (백업과 복원)

자동으로 되는 것

📁 미니ERP데이터
├─ 📄 erp-data.json ← 모든 데이터 (입력할 때마다 자동 저장)
├─ 📁 백업 ← 하루 1번 자동 백업, 최근 30일치
├─ 📁 증빙 ← 영수증 사진·PDF 원본
├─ 📁 세무사전달 ← 세무사에게 보낼 자료 묶음
└─ 📁 장부보관 ← 연도 마감한 지난해 장부

여기에 더해 구글드라이브가 이 폴더 전체를 클라우드에 복사해 둡니다. 컴퓨터가 고장 나도 새 컴퓨터에서 로그인만 하면 전부 돌아옵니다.

실수했을 때 되돌리기

1
데이터·설정 → [🕐 백업에서 복원] 버튼을 누릅니다.
2
날짜별 백업 목록에서 돌아가고 싶은 날을 골라 [이 시점으로 복원].
3
복원 직전의 데이터도 자동으로 한 번 더 백업되므로, 잘못 복원해도 다시 되돌릴 수 있습니다.

9다른 컴퓨터·휴대폰에서 쓰기

사무실 PC와 집 PC에서 같이 쓰기

1
두 번째 컴퓨터에도 구글드라이브를 설치하고 같은 구글 계정으로 로그인합니다.
2
프로그램을 열고 같은 폴더(미니ERP데이터)를 연결합니다. 끝 — 데이터가 그대로 보입니다.
⚠️ 두 곳에서 "동시에" 입력하지 마세요 한 번에 한 컴퓨터에서만 입력하는 것이 안전합니다. 만약 동시에 수정되면 "다른 곳에서 수정된 데이터가 있습니다"라는 경고가 뜨고, 어느 쪽을 살릴지 선택할 수 있습니다.

1

3

11문제가 생겼을 때 (Q&A)

증상해결 방법
노란 띠에 "폴더 다시 연결"이 떠요 버튼을 누르고 허용만 누르면 됩니다. 브라우저가 보안상 가끔 다시 묻는 것뿐이고 데이터는 그대로입니다.
저장 표시가 빨간색이에요 폴더 연결이 끊긴 상태입니다. 데이터·설정에서 폴더를 다시 연결하세요.
실수로 지웠어요 / 데이터가 이상해요 데이터·설정 → [🕐 백업에서 복원] → 어제 날짜를 골라 복원.
"다른 곳에서 수정된 데이터가 있습니다" 다른 컴퓨터에서 먼저 입력한 경우입니다. [불러오기]를 누르면 최신 내용을 가져옵니다.
재고 숫자가 실제와 달라요 품목·재고 → [재고조정]으로 실제 수량에 맞추세요(사유 입력). 매입이 "발주" 상태면 아직 재고에 안 잡힌 것이니 "입고완료"로 바꾸세요.
설치할 때 파란 경고창이 떠요 "Windows의 PC 보호" 창에서 추가 정보 → 실행. 무료 배포 프로그램이라 유료 서명이 없어 뜨는 안내입니다.
엑셀에서 CSV 한글이 깨져요 이 프로그램이 만든 파일은 깨지지 않습니다. 가급적 엑셀 다운로드(.xlsx) 버튼을 이용하세요.
Firefox·웨일에서 자동 저장이 안 돼요 폴더 연결은 크롬·엣지 전용 기능입니다. 크롬을 쓰시거나, 설정에서 JSON 내보내기로 수동 저장하세요.
💡 꼭 기억할 3가지 ① 폴더 연결만 하면 저장은 자동입니다.
② 받을 돈은 수금·지급 메뉴가 다 계산해 줍니다.
③ 신고는 세무사와, 자료 정리는 이 프로그램으로.
