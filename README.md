# 미니 ERP

> 중소기업·소상공인을 위한 **무료 업무 관리 프로그램**
> 설치도, 서버도, 월 이용료도 없습니다. 파일 하나로 시작하세요.

![라이선스](https://img.shields.io/badge/license-MIT-blue.svg)

## 이런 분들을 위해 만들었습니다

- 엑셀로 거래명세표·재고·미수금을 관리하다가 한계를 느낀 5~30인 회사
- 상용 ERP는 비싸고 복잡해서 부담스러운 소상공인
- 컴퓨터 비전문가도 쓸 수 있는 한국어 프로그램이 필요한 사무·회계 담당자

## 주요 기능

| 기능 | 설명 |
|---|---|
| 거래처·품목·재고 | 등록/검색, 재고 현황·입출고 이력·재고조정, 안전재고 경고 |
| 매출·매입 | 품목 여러 줄 입력, 부가세 자동 계산, 입고/출고 시점 재고 연동 |
| 수금·지급 | **부분 수금, 미수금·잔금, 연령 분석, 거래처 원장** |
| 배송·출고 | 상태 관리(상품준비→출고완료→배송중→배송완료), 송장 조회 링크 |
| 견적서·거래명세표 | 인쇄(PDF 저장), 거래명세표는 **실물 양식(A4 가로 2부, 전잔금/입금/총미수잔액)** |
| 회계 리포트 | 월별 손익, 거래처 순위, 부가세 참고 자료, CSV 내려받기 |
| 경비·증빙 | 지출 기록부, 영수증 파일 보관, **세무사 전달 패키지 자동 생성** |
| 장부·자체기장 | 매출장·매입장·현금출납부(일계/월계/누계), **연도 마감·이월** |
| 모듈 시스템 | 업종에 맞게 기능을 켜고 끄기 (서비스업은 재고 끄기 등) |

> ⚠️ **만들지 않는 것**: 세금 신고, 전자세금계산서 국세청 연동, 4대보험 계산.
> 법이 바뀌어도 프로그램이 낡지 않도록, 신고는 세무 전문가와 진행하세요.

> 📖 **처음 쓰시나요?** [매뉴얼.html](매뉴얼.html)을 브라우저로 열어 보세요.
> 구글드라이브 설치부터 세무사 자료 전달까지, 비전문가 기준으로 그림처럼 따라 할 수 있게 정리되어 있습니다. (A4 인쇄 가능)

## 사용 방법 ① — 웹형 (파일 하나로 바로 실행)

1. [Releases](../../releases)에서 **`미니ERP.html`** 을 내려받습니다.
2. 더블클릭하면 Chrome/Edge에서 열립니다. 끝!
3. **크롬에서 "프로그램처럼" 쓰기**:
   - Chrome 메뉴(⋮) → **저장 및 공유 → 바로가기 만들기** → "창으로 열기" 체크
   - 바탕화면 아이콘이 생기고, 독립 창 프로그램처럼 실행됩니다.

> 지원 브라우저: **Chrome, Edge** (자동 저장에 필요한 폴더 연결 기능 때문입니다).
> Firefox 등에서는 수동 JSON 내보내기/가져오기 모드로 동작합니다.

## 사용 방법 ② — 설치형 (.exe)

1. [Releases](../../releases)에서 **`미니ERP-Setup-x.x.x.exe`** 를 내려받아 설치합니다.
2. 시작 메뉴/바탕화면의 "미니 ERP"를 실행합니다.
3. 웹형과 **같은 데이터 폴더를 지정하면 데이터가 완전히 호환**됩니다.

## 데이터 저장 — 구글드라이브 연결 (추천)

이 프로그램은 서버가 없습니다. 데이터는 **내 PC의 폴더**에 저장됩니다.

1. PC에 [구글드라이브 데스크탑](https://www.google.com/drive/download/)을 설치합니다.
2. 프로그램 첫 실행 시 **[데이터 폴더 연결]** 버튼 → 구글드라이브 안에 폴더를 만들어 선택합니다.
   (예: `내 드라이브/미니ERP데이터`)
3. 이후는 자동입니다:
   - 입력할 때마다 **자동 저장** (사이드바에 "저장됨" 표시)
   - 하루 한 번 **자동 백업** (최근 30일분 보관)
   - 구글드라이브가 알아서 **클라우드 동기화·백업**

데이터 폴더 구조:
```
미니ERP데이터/
├─ erp-data.json      ← 모든 데이터 (사람이 읽을 수 있는 JSON)
├─ 백업/               ← 일별 자동 백업 (최근 30개)
├─ 증빙/               ← 영수증 원본 파일 (월별 폴더)
├─ 세무사전달/          ← 세무사 전달 패키지
└─ 장부보관/            ← 연도 마감 아카이브
```

## 자주 묻는 질문 (FAQ)

**Q. 데이터가 날아가면 어떡하죠?**
자동 저장 + 일별 백업 + 구글드라이브 동기화의 3중 안전장치가 있습니다.
`백업/` 폴더의 날짜별 파일을 설정 화면에서 [JSON 가져오기]로 복원할 수 있습니다.

**Q. 여러 PC에서 같이 쓸 수 있나요?**
같은 구글드라이브 계정으로 여러 PC에서 열 수 있습니다. 단, **동시에 입력하면 충돌 경고**가 뜹니다.
한 번에 한 PC에서만 입력하는 것을 권장합니다.

**Q. 휴대폰으로 찍은 영수증은 어떻게 넣나요?**
구글드라이브 모바일 앱으로 `증빙/` 폴더에 사진을 올린 뒤, 프로그램의 증빙 화면에서 등록하세요.

**Q. 부가세 신고는 되나요?**
안 됩니다. 리포트의 "부가세 참고 자료"는 내부 관리용입니다. 신고는 세무사/홈택스에서 진행하세요.
대신 **[세무사 전달 패키지]** 버튼으로 신고에 필요한 자료를 한 번에 정리해 드립니다.

**Q. 회사가 커져서 기능이 부족해요.**
이 프로그램은 오픈소스(MIT)입니다. `src/` 폴더의 코드를 자유롭게 고쳐 쓰세요.
모듈 레지스트리(`src/js/registry.js`)에 등록만 하면 새 메뉴가 자동으로 생깁니다.

## 개발자용

```bash
# 개발 서버 (src/ 폴더 서빙)
node serve.js

# 단일 HTML 번들 생성 → dist/미니ERP.html
node build.js

# 설치형 빌드 (electron/ 폴더 참고)
cd electron
npm install
npm run dist
```

- 순수 HTML/CSS/JavaScript, 런타임 의존성 0
- 저장 계층은 어댑터 패턴: 브라우저(File System Access API) / Electron(Node fs) / 폴백(수동 JSON)
- 자세한 설계는 [SPEC.md](SPEC.md) 참고
